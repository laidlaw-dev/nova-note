# nova-note

- A web based note taking app with functionality to create, view, edit and delete notes. Only notes created by a user can be seen by that user. Particular emphasis on creating notes as quickly as possible.
- Project name: nova-note.

## Technology

### Backend

AWS API Gateway, AWS Lambda, AWS Cognito, AWS SAM, typescript, nodejs

### Client

React, Vite, typescript, AWS Cognito, AWS Amplify
